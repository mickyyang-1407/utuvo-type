## 3. 這一輪改了什麼（PR 前先看）

**智慧整理（三平台同一份規則）**
- 規則正本：
  - macOS：`Sources/UTUVOTypeCore/CleanupPromptRules.swift`、`Sources/UTUVOTypeApp/SmartCleanup.swift`
  - iOS：`ios/Shared/SmartCleanup.swift`
  - Android：`android/app/src/main/kotlin/com/utuvo/type/SmartCleanup.kt`
- **改規則要三個平台一起改**，文字要一致。
- 新增的規則：
  - **自動條列**：列舉的項目、做事的步驟，整理成編號清單。
  - **後面推翻前面也算改口**：說「喔對、還是」之後改掉前面的決定時，只留最後的決定。
  - **沒有標點的改口**：「四點不對不對三點出發」→「三點出發」。「這樣不對」這類真的在講「不對」的句子會保留。
- 逐字稿送給 Claude 時包在 `<<<` / `>>>` 裡面，不然模型會把「你幫我…」當成在跟它說話。

**雲端辨識提示詞（Whisper prompt）**
- 新的 `cloudHints` 排序：個人字典 → 內建詞庫（先音訊、再 AI、再其他）→ 詞庫目錄。zh-TW 會先轉成繁體，最多 200 個字。
  - iOS：`ios/Shared/SpeechEngine.swift`
  - Android：`VocabularyPacks.cloudHints`
- 舊做法把醫療、法律詞庫和簡體字擠進提示詞，結果是辨識變差、回傳簡體。

**Android 麥克風（Pixel 7 實測）**
- 系統 `SpeechRecognizer` 跟我們自己的 `AudioRecord` 不能同時錄音：後開的那邊拿到聲音，另一邊只收到全零。
- 現在只讓 `CloudRecorder` 開麥克風，原始 PCM 經 `ParcelFileDescriptor.createPipe()` 用 `EXTRA_AUDIO_SOURCE`（Android 13+）餵給系統辨識器。
  - 相關函式：`UTUVOImeService.attachMicPipe` / `closeMicPipe`。
  - debug build 會在 log 印 `cloud recording samples=… peak=…`，可以用來確認沒有錄到全零。

**其他**
- 中文後面的 `...` / `…` 會統一成全形 `……`（`Normalizer`，Swift 和 Kotlin 兩邊都改了）。
- Android 注音 AI 選字（0c reranker，模型在 `android/app/src/main/assets/zc/`，MIT）。
- iOS 手機上的 Gemma 整理（給沒有 Apple Intelligence 的機型）、新手教學、使用統計。

## 4. 還沒做完、歡迎 PR

- **短句辨識錯字**：短句（幾個字）有時會被 Whisper 辨識錯。目前收集到的例子還不夠，有重現的例子很歡迎附在 issue 裡。
- **自動條列偶爾不穩**：同一句話有時條列、有時不條列。測試句在 `Tests/UTUVOTypeCoreTests/TypelessParityTests.swift`、`CleanupFidelityTests.swift`。
- **iPhone／macOS 新版**：上面這些改動還沒出到 App Store／官網版本。

## 5. 送 PR 的規則

- **API key 一律不進 repo。** key 是使用者在 App 裡自己輸入的（存在 Keychain／Android Keystore）。測試請用環境變數，不要寫進檔案。
- 改整理規則、正規化（`Normalizer`）時，三個平台的測試都要過：`swift test`、`:core:test`、iOS `iOSTests`。
- 介面文字用台灣用語、繁體中文；英文字串在 `android/app/src/main/res/values-en/` 和 iOS 的 `ios/Shared/Localizable.xcstrings`。
- 一個 PR 做一件事；有改行為的，請附上改前、改後的例子。

## English summary

- `main` (`d0cd536`) is synced with the internal dev branch. Released: macOS 0.1.8, iOS 0.3.1, Android 0.3.1.
- Build/test: `swift build && swift test`; `cd android && ./gradlew :core:test :app:testDebugUnitTest`; iOS via Xcode (`ios/UTUVO Type.xcodeproj`).
- **Cleanup prompt rules are shared across macOS/iOS/Android. Change all three together.**
- New in this sync:
  - Cleanup: auto-list, later-reversal and unpunctuated self-corrections.
  - `cloudHints` ordering for Whisper prompts (personal dictionary first, converted to Traditional for zh-TW).
  - Android single-mic-owner fix: PCM is piped to SpeechRecognizer via `EXTRA_AUDIO_SOURCE`.
  - CJK ellipsis normalization.
- Real-voice test recordings and benchmarks are not in the public repo, so some Android instrumentation tests that need them won't run.
- Never commit API keys. They are entered by the user in the app.
