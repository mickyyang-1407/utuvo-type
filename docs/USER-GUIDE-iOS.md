# UTUVO Type iOS 使用者手冊

> 適用版本：0.1.0 (iOS)。這份手冊寫給完全不碰程式碼的一般使用者。
> UTUVO Type 讓你「用說的」打字：講一句話，變成乾淨的繁體中文文字，
> 可以直接複製，也可以在任何 App 的輸入框裡直接插入。

## 1. 安裝與啟用鍵盤

UTUVO Type 有兩個部分：一個主 App（聽寫、歷史、設定），和一個可以在任何
App 裡用的鍵盤。裝好主 App 後，還要自己把鍵盤「打開」一次：

### 加入鍵盤

1. 打開 iPhone 的**設定**。
2. 點**一般**。
3. 點**鍵盤**。
4. 點最上面的**鍵盤**。
5. 點**加入新鍵盤…**。
6. 在清單裡點 **UTUVO Type**。
7. 加進去之後，點清單裡的 **UTUVO Type**，把**允許完整存取（Allow Full Access）**
   的開關打開，彈出的警告按**允許**。

### 為什麼一定要開「允許完整存取」

UTUVO Type 的鍵盤靠 iOS 內建的語音辨識服務把語音轉成文字，而 iOS 規定：
沒有完整存取權的鍵盤不能使用網路與語音辨識服務。所以：

- **沒開完整存取**：按麥克風不會開始錄音，狀態列會出現紅字
  「請在設定 → 鍵盤 → UTUVO Type 開啟『允許完整存取』」。空格、換行、刪除
  三個按鈕不受影響，照常可用。
- **開了完整存取**：麥克風功能正常。

> 補充：iOS 對所有第三方鍵盤都會顯示「完整存取可能會傳送你輸入的內容」
> 這類一般性警告。UTUVO Type 本身不做雲端聽寫——它用的是 Apple 的語音
> 辨識；要不要連雲端只有一個地方：「設定」分頁裡選配的雲端翻譯
> （見第 2 節），留空就完全不上網。

## 2. 主 App 的三個分頁（聽寫／歷史／設定）

打開 UTUVO Type 主 App，畫面最下方有三個分頁：**聽寫**、**歷史**、**設定**。
整個 App 是深色介面。

### 「聽寫」分頁

畫面上方有一排**語言選擇**（分段按鈕），可以選：

- 繁體中文
- 簡體中文
- 英文（美國）
- 日文
- 韓文

預設是**繁體中文**。錄音中不能切換語言。

中間是一顆大的**圓形麥克風按鈕**：

- 按一下開始錄音，講話時可以看到波動的音波動畫。
- 再按一下結束。

**麥克風下方會出現一顆膠囊，告訴你這次辨識走哪一條**（2026-09-11 新增）：

| 膠囊 | 意思 |
|---|---|
| 🔒 綠色「裝置端辨識・音訊不離機」 | 語音在這台 iPhone 上處理，不上網 |
| ☁️ 橘色「雲端辨識・音訊會送到 Apple 伺服器」 | 這台裝置／這個語言沒有裝置端辨識，改用 Apple 的伺服器 |

不想要橘色那條退路，就到 **設定 → 辨識與隱私** 打開「只用裝置端辨識」——
之後遇到不支援的情況會直接拒絕錄音並說明，不會靜悄悄上雲。

結束後畫面會出現兩張卡片：

- **逐字稿**：iOS 語音辨識聽到的原始內容（灰白色字）。
- **輸出**：經過清理後的正式結果——自動濾掉口頭語助詞、自我修正的贅字、
  把數字正規化，並套用你在「設定」加的個人字典替換。

「輸出」卡片下面有兩顆按鈕：

- **複製**：把輸出文字複製到剪貼簿，按鈕短暫變成「已複製」（約 1.5 秒後變回來）。
- **翻譯**：點開選單可選目標語言，把輸出翻成該語言；翻譯進行中按鈕顯示
  「翻譯中…」，結果會以「翻譯」卡片顯示。
  - 翻譯是**選配**功能，需要先在「設定 → 雲端翻譯（選配）」輸入 API key；
    沒填 key 時按鈕是灰色不可按，畫面會提示「翻譯需先在『設定 → 雲端翻譯』
    輸入 API key」。**留空＝完全本機，不連任何雲端。**

### 「歷史」分頁

每次完成一段聽寫，「輸出」的內容會自動存進歷史（最近的在最上面，最多保留 500 筆）。
**2026-09-11 起，在別的 App 用 UTUVO Type 鍵盤講的內容也會寫進來**，該筆日期旁邊
會有一個琥珀色的 **⌨︎ 鍵盤** 小標，方便跟主 App 打的分開。每一筆可以：

- 按**星號**圖示：加入／取消星標。
- 按**影印文件**圖示：複製這筆的輸出文字（複製成功會短暫變成打勾圖示）。
- 把該筆**往左滑**：出現紅色「刪除」按鈕。

還沒有任何紀錄時，畫面會顯示「還沒有紀錄——到「聽寫」講一句話，這裡就會出現。」

### 「設定」分頁

四個區塊：

**辨識與隱私**（2026-09-11 新增）
一個開關：**「只用裝置端辨識」**。

- **關著（預設）**：裝置端優先；這台裝置或這個語言不支援時改用 Apple 伺服器辨識，
  而且會在「聽寫」畫面上用一顆膠囊標示走的是哪一條（見上面「聽寫」分頁那段）。
- **打開**：音訊永遠不離開這台裝置。遇到不支援的語言或機型時會**直接拒絕錄音**
  並說明原因，不會偷偷改用雲端。

**個人字典**
兩個輸入框：左邊填「要替換的詞」，右邊填「替換成」，按**新增**。
之後聽寫時只要唸到那個詞，就會自動換成你要的字。
例如：「pik」→「Pik」。要刪掉某條，按該條右邊的垃圾桶圖示。

**雲端翻譯（選配）**
填入 DashScope API Key 才能用「聽寫」分頁的翻譯按鈕，按 **儲存** 寫入、按 **清除** 刪掉。

- Key 存在 **iOS 鑰匙圈（Keychain）**，而且標記為「只有這台裝置、解鎖後才可讀」——
  不會跟著 iCloud 或未加密備份跑（2026-09-11 從明文偏好設定搬過來，
  舊版存的 key 會在第一次讀取時自動搬家並刪掉明文）。
- **已存的 key 不會顯示回來**；欄位只用來輸入新值，下面那行只講「Keychain 已存一把 key
  （不顯示內容）」或「尚未設定；留空＝完全本機，不連任何雲端」。

**關於**
顯示版本（0.1.0 (iOS)）、辨識引擎（Apple Speech（裝置端優先））、
文字清理（UTUVOTypeCore deterministic normalizer）、鍵盤（同一套清理＋字典，寫回歷史）。

## 3. 在任何 App 裡語音打字

這是鍵盤的用法——不用切回 UTUVO Type 主 App，直接在別的 App 的輸入框裡打字：

1. 點任何輸入框叫出鍵盤。
2. **長按鍵盤左下角的地球鍵 🌐**，在彈出的清單裡選 **UTUVO Type**。
   （第一次使用建議先在 Safari 的網址列試試。）
3. 鍵盤會換成一排四個按鈕，由左至右：
   - **🎤 麥克風**（圖示）
   - **空格**
   - **換行**
   - **⌫ 刪除**（圖示）
4. 按一下**麥克風**開始錄音：按鈕會轉為紅色，下方狀態列顯示
   「**錄音中・雲端辨識（音訊會送到 Apple 伺服器）**」，並且即時顯示最近聽到的片段。
   你講的字會**邊講邊直接插入游標位置**。
5. 再按一下**麥克風**結束，狀態列顯示「整理中…」。

**講完那一刻，整段字會被換成清理後的版本**（2026-09-11 起）：濾語助詞、修掉
自我修正的贅字、數字正規化、套用你的個人字典——跟主 App 的「輸出」同一套規則。
你會看到最後文字跳動一次，那是它在把逐字稿替換掉，不是重複輸入。

同一筆也會寫回主 App 的「歷史」，標成 ⌨︎ 鍵盤來源。

⚠️ **鍵盤的辨識固定走 Apple 伺服器**（鍵盤 extension 的記憶體上限吃不住裝置端模型），
設定裡的「只用裝置端辨識」管不到鍵盤。需要音訊完全不離機時，請改用主 App 的「聽寫」分頁。

其他按鈕：

- **空格**：插入一個半形空格。
- **換行**：插入一行斷行。
- **刪除**：每按一下刪掉游標前一個字元（不是長按連刪）。

按下這三顆任何一顆，鍵盤就放掉「剛剛那段字是我插的」這個記憶——之後的辨識結果
會接在後面，不會回頭刪掉你手動編輯的內容。

## 4. 字典與歷史共享

2026-09-11 起，鍵盤與主 App **真的共用同一套處理**（之前只有儲存位置共用，
鍵盤端沒接上）。

**字典：主 App 加的詞，鍵盤立刻生效。**

- 個人字典存在 App Group（`group.com.utuvo.type`）的共用儲存區。
- 鍵盤在講完定稿時會跑跟主 App 同一份 `UTUVOTypeCore` 清理管線，字典替換
  一起套用。你在「設定」加完詞，下一次用鍵盤講話就會換。

**歷史：鍵盤打的字也會寫回主 App。**

- 在別的 App 用鍵盤講完的內容會寫進同一份歷史（最多 500 筆），回到主 App 的
  「歷史」分頁就看得到，該筆右上角標一個 **⌨︎ 鍵盤** 的小標。
- 存的是清理後的結果和原始逐字稿，跟主 App 聽寫的紀錄格式一樣。

**前提：鍵盤要開「允許完整存取」。** 沒開的話鍵盤讀不到 App Group，
字典和歷史都不會生效（而且鍵盤本來就需要它才能辨識）。

**講話當下看到的字會變。** 鍵盤是邊講邊把逐字稿插進去、講完再整段換成清理後的版本，
所以你會看到最後一瞬間文字被修正——這是正常的，不是重複輸入。

## 5. 權限

### 主 App（聽寫分頁）

第一次按麥克風時，iOS 會依序問你兩件事：

1. **麥克風**：「UTUVO Type 只在你按住聽寫時使用麥克風，把語音轉成文字。」
   拒絕的話，按麥克風會看到橘色警示
   「需要麥克風權限才能聽寫；請到系統設定開啟。」
2. **語音辨識**：「UTUVO Type 使用 iOS 語音辨識把你的口述轉成文字。」
   拒絕的話會看到「需要語音辨識權限；請到系統設定開啟。」

被拒絕後想反悔：**設定 → UTUVO Type**，把「麥克風」「語音辨識」打開。

### 鍵盤

鍵盤裡按麥克風時，程式會向 iOS 要求**語音辨識**授權；未授權時狀態列顯示
紅字「**需要語音辨識權限**」。

## 6. 已知限制

- **辨識語言固定**：鍵盤的辨識語言固定為**繁體中文台灣（zh-TW）**，不能切換。
  只有主 App 的「聽寫」分頁能選五種語言。
- **部分裝置／語言沒有裝置端辨識**：主 App 優先使用「不出網路」的裝置端辨識；
  不支援時會改用伺服器端辨識，但**畫面上一定會標示**（橘色雲朵膠囊「雲端辨識・
  音訊會送到 Apple 伺服器」）。不想要這個退路，就到設定打開「只用裝置端辨識」。
- **鍵盤永遠是伺服器辨識**：鍵盤 extension 的記憶體上限吃不住裝置端模型，
  所以鍵盤錄音時狀態列會直接寫「錄音中・雲端辨識（音訊會送到 Apple 伺服器）」。
  設定裡的「只用裝置端辨識」只管主 App，管不到鍵盤。
- **模擬器上錄不了音**：模擬器沒有麥克風輸入，按下去會顯示
  「找不到可用的麥克風輸入（模擬器通常沒有）」。這是預期行為，實機才測得到聽寫。
- **鍵盤記憶體上限**：iOS 對鍵盤擴充功能有嚴格的記憶體上限（大約幾十 MB），
  超過會被系統直接關掉。因此鍵盤刻意維持極簡（四個按鈕＋一行狀態列），
  也暫不搭載裝置端辨識模型。
- **歷史只保留 500 筆**：超過後最舊的自動被移除。
- **直向為主**：App 支援直向畫面。

## 7. 常見問題

### Q：鍵盤清單裡找不到「UTUVO Type」，要重開機嗎？

通常不用重開整台手機。先確認主 App 已安裝且至少打開過一次；再到
設定 → 一般 → 鍵盤 → 鍵盤 → 加入新鍵盤… 找 UTUVO Type。剛安裝完偶爾需要
把設定 App 收掉重開、或重開機一次才會出現——這是 iOS 的老毛病，不是你的操作錯。

### Q：切到 UTUVO Type 鍵盤時，正在打字的 App 直接閃退？

這是舊版本的已知 bug（鍵盤設定檔缺少語言宣告導致宿主 App 當掉，
2026-08-24 已修復；2026-09-11 進一步把該宣告寫進專案產生器 `project.yml`，
避免下次重產專案時又掉回去）。請更新到修復後的版本；若仍遇到，請回報。

### Q：按了麥克風，狀態列出現紅字，各代表什麼？

| 紅字訊息 | 意思與處理 |
|---|---|
| 「請在設定 → 鍵盤 → UTUVO Type 開啟『允許完整存取』」 | 鍵盤沒拿到完整存取權。照第 1 節的路徑打開 Allow Full Access。 |
| 「需要語音辨識權限」 | 語音辨識授權被拒或尚未同意。到設定 → UTUVO Type 打開「語音辨識」。 |
| 「辨識器不可用」 | 目前語音辨識服務暫時不可用（常見於剛開機、無網路時的伺服器端辨識）。稍後再試。 |
| 「無法啟動：（錯誤說明）」 | 錄音引擎啟動失敗，後面的文字是 iOS 給的原始原因（例如被其他 App 佔用麥克風）。關掉佔用麥克風的 App 再試。 |

### Q：在主 App 聽寫時出現橘色警示？

| 訊息 | 意思 |
|---|---|
| 「需要麥克風權限才能聽寫；請到系統設定開啟。」 | 到設定 → UTUVO Type 打開「麥克風」。 |
| 「需要語音辨識權限；請到系統設定開啟。」 | 同上，打開「語音辨識」。 |
| 「這個語言的辨識器目前不可用。」 | 所選語言的辨識器無法啟用，換一種語言或稍後再試。 |
| 「無法啟動錄音：（錯誤說明）」 | 錄音啟動失敗，參考 iOS 給的原因。 |
| 「辨識中斷：（錯誤說明）」 | 辨識過程出錯而中止（正常按停止不會出現這句）。 |

### Q：為什麼鍵盤打出來的字跟主 App 的「輸出」不一樣乾淨？

2026-09-11 起兩邊跑的是同一套 `UTUVOTypeCore` 清理（濾語助詞、自我修正、字典、
數字正規化），結果應該一致。唯一的差別是主 App 可能另外做選配的雲端翻譯，
鍵盤沒有這個功能。

如果鍵盤打出來的還是原樣逐字稿，八成是**沒開「允許完整存取」**——
鍵盤讀不到共用設定時只能原樣插入。

### Q：我的字典詞在鍵盤裡沒生效？

先確認鍵盤的「允許完整存取」是開的（設定 → 一般 → 鍵盤 → 鍵盤 → UTUVO Type）。
開了之後，主 App 加的詞下一次用鍵盤講話就會套用（見第 4 節）。

### Q：講完之後鍵盤裡的字閃了一下又變了，是不是打兩次？

不是。鍵盤是邊講邊把逐字稿插進去，講完那一刻整段換成清理後的版本
（刪掉舊的那幾個字、補上新的），所以會看到最後一次跳動。

### Q：我在鍵盤講到一半自己按了空格或刪除，會不會被鍵盤刪掉我的字？

不會。只要你按了鍵盤上的空格／換行／刪除，鍵盤就放掉「那段文字是我的」這個記憶，
之後的辨識結果會直接接在後面，不會回頭刪你的字。
