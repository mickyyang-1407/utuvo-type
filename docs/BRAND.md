# UTUVO Tiny Tools

## 系列概念

`UTUVO Tiny Tools` 是一組小而專注的原生 macOS 工具。每個 App 只解決一個
清楚的日常問題，自己有 menu bar 入口、自己的設定與資料邊界，不把所有功能
塞進一個巨型套件。

這條系列刻意和 UTUVO 音樂產品分開：不使用音符、波形、等化器、唱片、耳機或
錄音室語彙。它比較像一盒放在桌上的小工具，每顆都有自己的功能符號。

## 視覺規則

- 一個圓角 tile 或獨立 glyph，縮到 menu bar 仍能辨識。
- 一個主 accent 色，搭配深色功能細節；不靠產品文字辨認。
- 圖像要能用在 menu bar、popover header、Dock／Finder icon 與 README。
- 不放 wordmark、長句、模型名稱或技術名詞進 icon。
- 每個 App 有自己的功能 glyph，但共享「簡單、溫暖、可工具化」的幾何語氣。

## UTUVO Type 的 mark

Type 使用橘色語音泡泡，裡面放深紫色文字輸入游標與小句點：

> 說出來 → 變成文字 → 可以直接使用。

它不是麥克風，也不是音訊播放器；即使不看產品名稱，也能把它理解成
「把想法放進文字裡」的工具。

## 可延伸的系列例子

這些只是命名與 glyph 方向，不代表現在要同時開發：

- `UTUVO Type`：語音泡泡＋輸入游標，語音轉文字。
- `UTUVO Clip`：兩張重疊紙片，快速整理剪貼簿。
- `UTUVO Nudge`：一個向前推的小圓角箭頭，提醒與待辦。
- `UTUVO Drop`：一個落入容器的方塊，檔案快速投遞與轉換。

共同原則是「一顆小工具、一個主要動作」，而不是把系列做成另一個大型
音樂或 AI 平台品牌。
