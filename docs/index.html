Local-first dictation for macOS

Speak.
It types.

A menu bar app that turns your voice into clean, paste-ready text. Transcription runs on your Mac. Cleanup is deterministic first, model second. Nothing leaves the machine unless you say so.

It lands where your cursor is

Punctuation, fillers, numbers and your own dictionary — cleaned up and pasted into the app you're in.
Four modes

Pick how much help you want.

Fast never calls a large model. The others only do what you ask, and fall back to the deterministic path if a model fails.

Fast Dictate

Transcribe and normalize on-device. Instant, predictable, no LLM.

Smart Dictate

A small local editor tidies sentences. Still on your Mac.

Edit Selection

Select text, say what to change. The rewrite replaces the selection.

Deep / Long Note

Long-form notes with a larger model — local 27B or cloud, only when you choose it.

Built for Traditional Chinese

Cleanup you can predict.

Most of the polish is rules, not guesses. The same input gives the same output, every time.

  • Chinese punctuation, spacing between CJK and Latin, filler words removed
  • Numbers, dates and amounts written the way you'd type them
  • Taiwan wording for software and everyday terms; mixed English stays English
  • A personal dictionary for names, products and jargon
  • Per-app presets: a terse style for chat, a fuller one for documents
Private by default

Your voice stays on your Mac.

The default install is fully local: Qwen3-ASR 0.6B running through MLX on Apple silicon. No account, no telemetry, no network after setup.

  • Accessibility is used to read the focused field and paste back — never the whole screen
  • Recording is always announced by the capsule and a sound cue
  • Cloud formatting is a separate, opt-in adapter with your own key, stored in the Keychain
  • Everything is in the open: read the routing rules, run the benchmark, audit the prompts
Native, top to bottom

Liquid Glass. Light and dark.

Swift, AppKit and SwiftUI. Built against the macOS 26 design language with a Liquid Glass popover, floating sidebar and a tiny overlay capsule — and a plain material fallback on macOS 14 and 15.

Install

Three commands.

Or grab the signed, notarized build from Releases. Building from source takes about a minute plus a one-time 1.2 GB model download.

git clone https://github.com/mickyyang-1407/utuvo-type.git && cd utuvo-type
./scripts/bootstrap-runtime.sh   # Python venv + Qwen3-ASR model, one time
./scripts/build-app.sh           # dist/UTUVO Type.app
Apple silicon for the local enginemacOS 14+ · Liquid Glass on 26+8 GB memory for Fast · 16 GB for the local editor~1.5 GB disk for the modelIntel Macs can use cloud or built-in speech

The DMG is small: the speech model is not inside it. Settings → General → Install Local Engine downloads Qwen3-ASR 0.6B (about 1.2 GB, once) into your Application Support folder. Nothing is downloaded until you click.
