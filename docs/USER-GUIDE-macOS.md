# UTUVO Type — macOS 使用者手冊

UTUVO Type 是一個裝在 macOS 選單列（menu bar）的語音輸入 App：你對著麥克風說話，
它把語音變成整理好的文字，直接貼進你目前正在打字的輸入框。

這份手冊寫給完全不懂技術的使用者。所有按鈕名稱、預設值都照 App 裡實際顯示的文字。

---

## 1. 第一次打開

### 1.1 找到 App

UTUVO Type 啟動後**不會跳出視窗**——它住在螢幕右上角的選單列上，圖示是一個
「語音泡泡＋文字游標」的小 logo。點一下這個圖示，會彈出一個面板，上面寫著
**「UTUVO TYPE」** 和 **「こえ・タイプ ✦ 語音輸入」**。

### 1.2 授權兩個系統權限

第一次點選單列圖示時，面板最上方會出現一張權限卡片（有一個盾牌圖示），App 會帶你去
「系統設定」的對應頁面。App 一共需要：

| 權限 | 用途 | 去哪裡授權 |
|---|---|---|
| **麥克風** | 錄下你說的話 | 系統設定 → 隱私權與安全性 → 麥克風，把 UTUVO Type 打開 |
| **輔助使用（Accessibility）** | 把辨識結果「貼回」你目前的輸入框、讀取 Edit Selection 要改寫的選取文字 | 系統設定 → 隱私權與安全性 → 輔助使用，把 UTUVO Type 打開 |

> 另外還有一個「語音辨識」權限，但**平常不會遇到它**：只有在你沒有安裝本機語音引擎、
> App 需要改用 macOS 內建語音辨識時，才會向你要這個權限。

### 1.3 授權沒開時，畫面會顯示什麼

權限卡片會依缺哪些權限顯示不同的文字（以下是繁中介面的原文）：

- 兩個都缺：
  - 標題：**「先完成一次系統授權」**
  - 說明：「需要麥克風與輔助使用，才能錄音並貼回目前輸入框。」
  - 按鈕：**「開啟系統權限」**
- 只缺麥克風：
  - 標題：**「還缺麥克風權限」**
  - 說明：「輔助使用已完成；只需要開啟麥克風即可開始聽寫。」
  - 按鈕：**「開啟麥克風設定」**
- 只缺輔助使用：
  - 標題：**「還缺輔助使用權限」**
  - 說明：「麥克風已完成；只需要開啟輔助使用即可貼回文字。」
  - 按鈕：**「開啟輔助使用設定」**

點按鈕就會直接打開系統設定裡正確的那一頁，把 UTUVO Type 的開關打開後回到 App 即可。
設定視窗裡也有權限狀態列（顯示 READY／MISSING）和 **「打開系統設定」** 按鈕。

> 這個提示流程只會主動跑一次；之後如果權限還沒開好，面板上會一直留著那張權限卡，
> 直到你去系統設定把它打開為止。

## 2. 四個工作模式

點選單列圖示後，面板中間有一區 **WORK MODES**，四張卡片各代表一種模式，點一下就切換，
被選中的卡片右上角會顯示 **ON**。目前使用的模式也會顯示在面板上方（ACTIVE: …）。

| 卡片上的名稱 | 小字說明 | 什麼時候用它 |
|---|---|---|
| **FAST DICTATE** | 最快・不呼叫 LLM | 日常講一句話就貼上去。例如在訊息軟體跟同事說「等一下開會」，按下熱鍵講完再按一次，文字立刻貼上。這個模式完全不連雲端、不做 AI 潤稿，最快也最省電，也是 App 的預設模式。 |
| **SMART DICTATE** | 本機小型 editor | 口述比較正式的內容，希望順便去掉贅詞、排好標點。例如口述一段給客戶的留言，希望「嗯、那個」被清掉。 |
| **EDIT SELECTION** | 改寫目前選取 | 先在文件裡選取一段字，再錄音下指令。例如選取一段草稿後說「改成更白話」，App 會把改寫結果替換回去。 |
| **DEEP / LONG NOTE** | 隨你的設定變動（見下） | 長文、會議紀錄這類大段內容。這是手動才會啟用的模式，不會自動觸發，也不會自動下載任何大型模型。 |

**Deep 到底會走什麼？**（2026-09-11 起卡片小字會直接告訴你，不用猜）

| 你的設定 | 卡片小字 | 實際行為 |
|---|---|---|
| 設定 → 模型 → 「Deep 本機 model」有填 | 本機 Deep・<你填的 model> | 用你指定的本機大模型整理，不連雲端 |
| 沒填，但後端切到「百鍊」 | 雲端 qwen3.7-plus | 走雲端 plus；失敗會退回 flash，再不行退回本機整理 |
| 兩者都沒有 | 未設 Deep model・照 Smart 走 | 行為跟 Smart 一樣，不會偷偷升級模型 |

選 Deep 這個動作本身就是「我同意用大模型」，沒有第二個開關要打勾。

補充：

- 面板上還有兩個快速按鈕 **「Edit Selection」** 和 **「Deep / Long Note」**，
  可以不切換預設模式、直接以該模式開始一次錄音。
- 主按鈕的文字會隨狀態變化：平時是 **「開始聽寫」**，錄音中變成紅色的
  **「停止・整理貼上」**。按 Esc 也可以取消目前的錄音或處理。

## 3. 快捷鍵

### 3.1 出廠預設

聽寫快捷鍵的出廠預設是 **⌥Space**（Option ＋ 空白鍵）。

如果你的 ⌥Space 已經被 Gemini、ChatGPT、Raycast、Alfred 這類 App 佔走，
UTUVO Type 會自動改用退路鍵 **⌥`**（Option ＋ 反引號／Esc 下面那顆鍵）繼續運作，
同時在選單列面板顯示一張衝突卡（見 3.3）。退路鍵只是暫時的，不會存進設定；
等你把 ⌥Space 解除之後，按衝突卡上的 **「重試」** 就會回到 ⌥Space。

設定視窗裡有 **「恢復預設 ⌥Space」** 按鈕可以隨時改回來。

### 3.2 怎麼改快捷鍵

打開設定（面板右上角的齒輪圖示），到 **「快捷鍵與門檻」** 分頁：

1. 點 **「快捷鍵」** 那一列的錄製按鈕，然後直接按下你想用的按鍵組合。
   支援 F1–F20、Fn＋字母／數字，以及 ⌘⌥⌃⇧ 修飾鍵組合。
2. 改完立即生效，不需要重開 App。畫面會顯示
   「目前快捷鍵：⌥Space。修改後會立即重新註冊，不需要重開 App。」這樣的提示。
3. 按 **「清除」** 可以不要快捷鍵（仍然可以用選單列面板的主按鈕開始聽寫）。

另外在 **「一般」** 分頁也有同一個快捷鍵錄製器，以及 **「按住說話」（Push to Talk）**
開關：打開後變成「按住快捷鍵錄音，放開後停止並貼上」；關閉則是「按一下開始，
再按一下停止」。

### 3.3 跟 Gemini／Raycast 等 App 撞鍵時

撞鍵時選單列面板會出現一張**衝突卡**（鍵盤加刪節號圖示）。卡的內容：

- 出廠預設 ⌥Space 被佔用、正在用退路 ⌥` 時，標題是
  **「⌥Space 已被 ○○ 佔用」**（○○ 是偵測到的 App 名稱，例如 Gemini；偵測不到就寫
  「另一個 App」）。
- 下一行是解除路徑，例如：
  - Gemini：「Gemini → 設定 → 鍵盤快捷鍵」
  - ChatGPT：「ChatGPT → 設定 → 鍵盤快捷鍵」
  - Raycast：「Raycast → 設定 → General → Raycast Hotkey」
  - Alfred：「Alfred → General → Alfred Hotkey」
  - 找不到來源時：「找不到確切來源；請檢查其他啟動中的 App 或登出再試一次。」
- 再一行提示：「目前暫用 ⌥`，解除後按重試即可回到 ⌥Space」。
- 卡上有三顆按鈕：**「重試」**（重新註冊 ⌥Space）、
  **「改用 ⌥`」**（乾脆把快捷鍵固定成退路鍵）、**「知道了」**（關掉卡片）。

就算你先不理它，執行期間熱鍵被別的 App 搶走時，UTUVO Type 也會自動搶回來並顯示
「⌥Space 與 ○○ 撞鍵（已自動取回）」，副標說明「Type 每次被搶都會自動取回；
想根治請到下面路徑解除。」

### 3.4 修飾鍵＋聽寫鍵＝直接貼翻譯

設定 → **「一般」** 分頁有一張 **「即時翻譯」** 卡片，三個下拉選單各綁一個修飾鍵：

| 組合 | 預設 | 說明 |
|---|---|---|
| **⇧ + 你的聽寫鍵** | 由你在下拉選單指定 | 講完之後貼上該語言的翻譯，而不是原文 |
| **⌘ + 你的聽寫鍵** | 同上 | |
| **⌃ + 你的聽寫鍵** | 同上 | 這一槽用 ⌃ 不用 ⌥——⌥＋F14 會被 macOS 的螢幕選項吃掉 |

可選語言有 17 種（英、日、韓、法、德、西、義、葡、俄、泰、越、印尼、阿拉伯、
印地、荷、簡中、繁中），也可以設成 **off** 讓那個組合不做事。

**toggle 模式下，決定語言的是你「停止」那一下按的修飾鍵**——可以先講完，再決定要翻成什麼。

翻譯要走雲端（需要 §5 的 API key）。沒設定 key 時這功能不會有反應。

## 4. 字典替換

語音辨識常常把公司名、人名、產品名認錯。「個人字典」讓你指定某個詞要被換成正確寫法。

### 4.1 怎麼加詞

打開設定 → 左側 **「個人字典」** 分頁：

1. 在左邊輸入框輸入要被替換的詞（提示文字：「新增詞彙，例如：UTUVO Type」）。
2. 在右邊輸入框輸入想換成的寫法（提示文字：「輸出寫法（可留空）」；留空代表維持原樣）。
3. 按 **「加入」**。詞條會以小卡片列出，卡片右側的 × 可以移除；
   底部的 **「清空全部」** 會清掉整份字典。

字典會套用到本機文字整理，也會當作 ASR 的 context 提示。

### 4.2 右邊界規則（什麼情況會換、什麼情況不會換）

替換只發生在「這個詞後面不是另一個字」的時候。判斷方式：緊接在詞後面那一格如果是
**文字（中文、英文字母、數字、底線）就不換；如果是標點、空白或句子結束才換**。
詞的前面則不受限制（可以直接黏著中文字）。

舉例——假設你在字典加了「pik → 皮克」：

| 你說出／辨識成的文字 | 結果 | 原因 |
|---|---|---|
| `pik，` | 換成「皮克，」 | 後面是逗號，不是文字 |
| `pik` （句尾） | 換成「皮克」 | 後面沒有字了 |
| `pik工作` | **不換**，維持「pik工作」 | 後面緊接著「工」，看起來只是更長詞的一部分 |

所以如果你發現某個詞沒被換掉，通常表示辨識結果裡它後面黏了其他字——
這時請把完整的長詞一起加進字典（例如把「pik工作」整個加為一條）。

字典除了替換，還會自動做這些整理：移除口頭贅詞（嗯、啊、那個、這個…）、
壓掉口吃重複（「我我覺得」→「我覺得」）、自我修正（「不是 A，是 B」→ 只留 B）、
中文數字轉阿拉伯數字（「二〇二六年八月」→「2026 年 8 月」、「五點半」→「5:30」、
「一百二十三元」→「123 元」）、以及條列線索轉換行（「第一…第二…第三…」各自換行）。

## 5. 雲端 provider（百鍊）

### 5.1 什麼時候才會用到雲端

預設是 **LOCAL（本機優先）**：Fast 模式永遠只用本機引擎＋上述的整理規則，
不需要網路、不需要帳號、不需要 API key。只有你手動把後端切到 **「百鍊」**
（設定 → 「快速路徑」分頁 → 「ASR／整理後端」下拉選單，可選「本機優先」或「百鍊」）
之後才會用到雲端。

### 5.2 怎麼設定

**先搞清楚你的百鍊帳號是哪一種**（2026-09-11 實測，踩過才知道）：

| 帳號型態 | 要用的網域 | key 形狀 |
|---|---|---|
| 按量付費（一般 DashScope API key） | `dashscope.aliyuncs.com` | `sk-` ＋ 32 字元 |
| 訂閱制（Agent Plan／Token Plan） | `token-plan.cn-beijing.maas.aliyuncs.com` | `sk-` ＋ 111 字元 |

**拿訂閱制的 key 去打 dashscope 會回 401**——看起來像 key 壞掉，其實是網域不對。
設定頁有兩顆按鈕可以一鍵切換這兩組網址，不用自己拼。

設定 → **「雲端（選配）」** 分頁，可以填三個欄位（都已預填官方位址）：

- **ASR WebSocket endpoint**
- **Formatter endpoint**
- **Workspace ID（可留空）**

**API key 直接在同一頁填**（2026-09-11 新增，以前只能開終端機）：同一張「百鍊 API key」
卡片裡有一個密碼欄位，貼上 key 後按 **「儲存」**，App 會把它寫進 macOS 鑰匙圈
（Keychain，項目為 service `com.utuvo.type.bailian`、account `api-key`）。按 **「清除」**
可以整個刪掉。

幾個要知道的：

- **已存的 key 永遠不會顯示回來。** 欄位只用來輸入新值；卡片下方那行狀態只講
  「Keychain 已有一把 key（不顯示內容）」或「Keychain 目前沒有 key；本機模式照常可用」。
- **環境變數優先於 Keychain。** 如果你的 shell 有設 `UTUVO_TYPE_BAILIAN_API_KEY`
  或 `DASHSCOPE_API_KEY`，卡片會出現一行橘色警告，提醒你「這裡存的 key 不會生效」——
  因為 App 讀 key 的順序是先環境變數、後 Keychain。
- App 不會把 key 顯示在任何欄位、log 或貼上結果裡。「模型」分頁另外會顯示偵測狀態。

### 5.2a 貼完 key 按「測試雲端連線」

同一張「百鍊 API key」卡片最下面有一顆 **「測試雲端連線」**（2026-09-12 新增）。
按下去會用**目前的 key 與 formatter 端點**實際送一句話，照 fallback 鏈逐個試模型，
然後把結果列出來，例如：

```
❌ qwen3.7-flash-2026-07-15 — HTTP 404
❌ qwen3.7-flash — HTTP 404
✅ qwen3.6-flash 712ms
輸出：等一下四點開會。
```

它**不會改任何設定**，也不會動你的後端選擇；純粹告訴你「key ＋ 端點 ＋ 模型」這三樣
現在對不對。整條鏈都失敗時會把每一個模型的錯誤都列出來，方便判斷是 key 錯（401）
還是端點／模型錯（404）。

### 5.2b 模型名稱可能對不上（會自動退，但會慢一點）

訂閱制端點上實際可用的模型只有 12 個，產品預設的 primary
（`qwen3.7-flash-2026-07-15`）不在其中。這不會壞掉——fallback 鏈會自動往下試，
實測第三個 `qwen3.6-flash` 會成功：

```
❌ qwen3.7-flash-2026-07-15   0.58s  404 → 換下一個
❌ qwen3.7-flash              0.47s  404 → 換下一個
✅ qwen3.6-flash              0.71s  → 我們今天下午四點要在錄音室開會討論母帶交付。
```

代價是每次多 1 秒左右在兩個不存在的模型上。嫌慢的話到「模型」分頁把 primary
改成端點上真的有的名字。

### 5.3 沒設定 key、或雲端失敗時會怎樣

- 完全沒設 key 也可以照常用：本機 Fast 模式不受影響（設定頁原話：
  「目前不需要登入或 API key 也能使用本機 Fast」）。
- 切到百鍊後若雲端逾時或失敗，App 會**保留原始 transcript**，先套用本機的
  deterministic 整理，再把可用結果貼出去——你不用重新錄一次。

## 6. 歷史記錄

每一次聽寫的原始文字、整理結果和錄音檔都會留在你的 Mac 上（不上傳）。

- **存在哪**：錄音檔在
  `~/Library/Application Support/UTUVO Type/Recordings/`；
  歷史資料本身保存在 App 自己的偏好設定裡。設定 → 「關於」分頁的
  **「App 資料位置」** 卡片列出資料、錄音、Log 三個位置，每個都有 **「打開」** 按鈕。
- **怎麼看**：設定 → **「歷史紀錄」** 分頁。紀錄按月份摺疊，點月份展開。
  每筆紀錄可以：**播放**（聽當時的錄音）、**複製**、**加星標／取消星標**、
  **重試**（重新整理一次），或按垃圾桶圖示刪除單筆。
  展開「原始 transcript」可以看到未整理的原稿。
- **怎麼清**：
  - 清全部：歷史紀錄分頁的 **「清空歷史」** 按鈕，確認對話框會提醒
    「這會一併刪除 Type 自己保存的錄音檔，無法復原。」，按 **「清空全部」** 執行。
  - 自動清理：設定 → 「進階」→ 「歷史紀錄」卡片，可設定
    「歷史筆數上限」（預設 20 筆，上限 500）和
    「自動刪除錄音」（保留全部／僅保留最新 N 筆／一天／一週／一個月）。
    加了星標的紀錄不會被自動清理刪掉。

## 7. 常見問題

### Q1：按了快捷鍵沒反應？

1. 先看選單列面板有沒有出現**衝突卡**。有的話代表熱鍵被別的 App 佔走了：
   照卡上的「解除路徑」去把對方的快捷鍵關掉，再按 **「重試」**；或直接按
   **「改用 ⌥`」** 換一顆鍵。
2. 如果你在「一般」或「快捷鍵與門檻」分頁把快捷鍵清掉了，面板主按鈕下方會顯示
   「未設定快捷鍵・仍可點擊按鈕」——此時直接點選單列圖示按 **「開始聽寫」** 就好。
3. 使用 Fn 開頭的組合（例如 Fn＋A）時，需要輔助使用權限；沒授權會收到
   「Fn 快捷鍵需要輔助使用權限；請先在系統設定授權後重新設定」的提示。

### Q2：錄音沒聲音／辨識不到我說話？

1. 檢查麥克風權限：面板的權限卡會顯示「還缺麥克風權限」，按
   **「開啟麥克風設定」** 去系統設定打開。
2. 設定 → 「一般」→ 「音訊」卡片：確認「麥克風」選的是對的裝置（或「系統預設」），
   必要時按 **「重新整理」**。如果列表抓不到裝置，App 會顯示
   「目前沒有可列出的輸入裝置；請確認麥克風已連接並允許 UTUVO Type 使用。」
3. 多聲道裝置（如混音器）可在「輸入聲道」換一個聲道試試。
4. 第一次使用本機引擎時模型需要載入，第一句可能比較慢；之後就會變快。

### Q3：辨識完成但文字沒貼進去？

多半是**輔助使用（Accessibility）權限**沒開——貼回輸入框靠的就是它。

1. 面板會顯示「還缺輔助使用權限」，按 **「開啟輔助使用設定」**，
   到系統設定把 UTUVO Type 打開。
2. 也可以到設定 → 「快捷鍵與門檻」→ 「系統權限與最近結果」按
   **「要求輔助使用權限」**。
3. 授權後如果功能還是怪怪的，回到 UTUVO Type 再試一次即可（App 也是這樣提示的）。

### Q4：其他小提醒

- 錄音中按 **Esc** 可以隨時取消。
- 面板底部 **「複製」** 可以複製最近一次結果；設定裡也有 **「複製最後結果」** 按鈕。
- 想讓 App 開機自動啟動：設定 → 「進階」→ 「登入時自動啟動」；
  **「啟動時隱藏」** 打開後它只會待在選單列。
