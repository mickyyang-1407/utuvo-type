iPhone 與 Mac 的語音輸入

你說。

iPhone

一個有光球的鍵盤。

按地球鍵切到 UTUVO Type 就能開口說。光球會跟著你的聲音動；說完再點一下，整理好的文字只會插入一次，就在游標的位置。

長按光球翻譯

滑到語言放開。說中文，打出英文或日文——語言可以自己挑，最多五種。

說出要怎麼改

選取一段文字，說「改成正式一點」或「加上時間」，改好的版本直接取代選取——在裝置上用 Apple Intelligence，或用你自己的雲端 key。

打錯字，當場改

EN、繁、简 就在光球旁邊。用英文、注音或拼音改一個字——繁體簡體都行——改完點「語音」繼續說。

說過的話，都留在手機上

每次聽寫都存在手機裡，可以搜尋、加星號、一鍵複製。個人字典讓它學會你常講的人名和專有名詞。

繁體與簡體中文

app 跟著 iPhone 的語言走：繁體中文用台灣用語，簡體中文用大陸用語。也能用英文聽寫。

Mac

一個選單列 app，寫什麼都能用。

在你的 Mac 上用本機模型轉錄。整理先靠規則，要你開口才用模型。

  1. 按快捷鍵

    預設是 ⌥Space，按住不放就是 push-to-talk，快捷鍵可以自己改。

  2. 開口說

    螢幕上會出現一顆小膠囊表示正在錄音，按 Esc 取消。沒按快捷鍵的時候麥克風不會開。

  3. 貼到游標所在的地方

    整理完標點、贅詞、數字和你字典裡的詞之後，直接貼進你正在用的 app。

Fast Dictate

本機轉錄加規則整理，最快，結果也最可預期。

Smart Dictate

本機的小型 editor 幫你順句子，一樣不出這台 Mac。

Edit Selection

先選一段文字，再用講的說要改什麼，改好的版本直接取代原本那段。

Deep / Long Note

長篇筆記交給比較大的模型，本機 27B 或雲端都可以，要你自己選才會用。

隱私

不用帳號。不追蹤。程式碼開源。

iPhone

  • 裝置端辨識優先；打開「只用裝置端辨識」，音訊就永遠不離開手機
  • 改寫與翻譯在裝置上用 Apple Intelligence；雲端 key 是選配，用你自己的
  • 鍵盤不會記錄你用其他按鍵打的字
  • 需要「允許完整存取」只是因為 iOS 不讓鍵盤用麥克風，鍵盤要請 app 代為錄音

Mac

  • 預設引擎在本機跑：Apple silicon 上用 MLX 執行 Qwen3-ASR 0.6B
  • 輔助使用權限只用來讀目前的輸入欄位並貼回去，不會讀整個螢幕
  • 雲端整理要你自己打開，key 存在鑰匙圈
  • 路由規則、提示詞、benchmark 都在 repo 裡

完整說明請看隱私權政策。
