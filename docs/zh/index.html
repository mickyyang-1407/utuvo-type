本機優先的 macOS 語音輸入

你說。
它打字。

住在 menu bar 的語音輸入。你講話，它在你的 Mac 上轉成文字、整理好，貼到游標所在的地方。整理大多靠規則，模型只在你選的模式裡介入。沒有打開雲端的話，不會有任何東西離開這台電腦。

下載 Mac 版 看原始碼

免費・開源・MIT・不用帳號、不用 API key

1

按快捷鍵

預設是 ⌥Space，按住不放就是 push-to-talk，快捷鍵可以自己改。
2

開口說

螢幕上會出現一顆小膠囊表示正在錄音，按 Esc 取消。沒按快捷鍵的時候麥克風不會開。
3

貼到游標所在的地方

整理完標點、贅詞、數字和你字典裡的詞之後，直接貼進你正在用的 app。
四種模式

差別在模型介入多少。

Fast 完全不用大模型。其他三種只在你選的時候才用模型，模型出錯就退回規則路徑。

Fast Dictate

本機轉錄加規則整理，最快，結果也最可預期。

Smart Dictate

本機的小型 editor 幫你順句子，一樣不出這台 Mac。

Edit Selection

先選一段文字，再用講的說要改什麼，改好的版本直接取代原本那段。

Deep / Long Note

長篇筆記交給比較大的模型，本機 27B 或雲端都可以，要你自己選才會用。

為繁體中文而做

整理的結果可以預期。

大部分整理靠規則，同樣的輸入每次都得到同樣的輸出。

  • 補中文標點，中英文之間留空格，去掉贅詞
  • 數字、日期、金額照你平常打字的寫法
  • 用台灣的用語，夾在中間的英文照原樣保留
  • 個人字典，放人名、產品名和專有名詞
  • 可以依 app 設定風格，例如聊天軟體用短句，文件用完整句子
預設不連網

你的聲音留在你的 Mac 上。

預設安裝就是純本機，語音辨識用 Qwen3-ASR 0.6B，透過 MLX 在 Apple silicon 上跑。不用帳號，沒有遙測，模型裝好之後不需要網路。

  • 輔助使用權限只拿來讀目前的輸入框和貼回文字，不會讀整個螢幕
  • 錄音時一定有膠囊和提示音
  • 雲端整理要自己打開，用你自己的 API key，key 存在 Keychain
  • 程式碼全部公開，路由規則、benchmark 和 prompt 都在 repo 裡
原生 macOS app

Liquid Glass 介面，深淺色都有。

用 Swift、AppKit 和 SwiftUI 寫的。介面照 macOS 26 的 Liquid Glass 做，menu bar 面板、浮動側欄和錄音時的小膠囊都是玻璃；macOS 14 和 15 會退回一般材質。

Install

三行指令。

也可以直接到 Releases 下載已簽名、已公證的版本。從原始碼建置大約一分鐘，另外要下載一次 1.2 GB 的模型。

git clone https://github.com/mickyyang-1407/utuvo-type.git && cd utuvo-type
./scripts/bootstrap-runtime.sh   # Python venv＋Qwen3-ASR 模型，一次性
./scripts/build-app.sh           # dist/UTUVO Type.app
本機引擎需要 Apple siliconmacOS 14+・26+ 有 Liquid GlassFast 需 8 GB 記憶體・本機 editor 建議 16 GB模型約占 1.5 GBIntel Mac 可走雲端或系統內建語音

DMG 本身很小，語音模型不在裡面。開啟設定 → 一般 → 安裝本機引擎，會把 Qwen3-ASR 0.6B（約 1.2 GB）下載到你的 Application Support 資料夾，只下載這一次，而且要你按了才會開始。
