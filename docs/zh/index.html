本機優先的 macOS 語音輸入

你說。
它打字。

一個 menu bar 小工具，把你的聲音變成乾淨、可直接貼上的文字。轉錄在你的 Mac 上跑；整理先走確定性規則，模型只是輔助。你不點頭，什麼都不會離開這台機器。

下載 Mac 版 看原始碼

免費・開源・MIT・不用帳號、不用 API key

1

按快捷鍵

預設 ⌥Space，按住就是 push-to-talk。想換哪顆鍵都行。
2

開口說

小膠囊告訴你正在錄。Esc 取消。你沒按之前不會錄任何東西。
3

落在游標所在的地方

標點、贅詞、數字、你的個人字典——整理好，貼進你正在用的 app。
四種模式

你決定要多少幫忙。

Fast 永遠不呼叫大模型。其他模式只做你要求的事，模型失敗就退回確定性路徑。

Fast Dictate

本機轉錄＋規則整理。即時、可預期、沒有 LLM。

Smart Dictate

本機小型 editor 順句子。還是在你的 Mac 上。

Edit Selection

選一段文字，說你要改什麼。改寫結果直接取代選取。

Deep / Long Note

長文筆記交給大一點的模型——本機 27B 或雲端，只在你選擇時。

為繁體中文而做

看得懂的整理邏輯。

大部分的修飾是規則，不是猜測。同樣的輸入永遠得到同樣的輸出。

  • 中文標點、中英之間的空格、贅詞去除
  • 數字、日期、金額寫成你自己會打的樣子
  • 台灣用語（軟體、日常詞）；夾雜的英文保持英文
  • 個人字典：人名、產品名、術語
  • 依 app 的預設：聊天用簡短風格、文件用完整風格
預設就是私密

你的聲音留在你的 Mac 上。

預設安裝完全本機：Qwen3-ASR 0.6B 透過 MLX 在 Apple silicon 上跑。沒有帳號、沒有遙測、裝好之後不需要網路。

  • 輔助使用只用來讀取目前輸入框與貼回——從不讀整個螢幕
  • 錄音一定有膠囊與提示音，不會偷偷錄
  • 雲端整理是獨立、需要你打開的 adapter，用你自己的 key，存在 Keychain
  • 全部公開：路由規則看得到、benchmark 跑得動、prompt 查得到
從頭到尾都是原生

Liquid Glass。淡色與深色。

Swift、AppKit 與 SwiftUI。依 macOS 26 的設計語言：Liquid Glass 面板、浮動側欄、一顆小小的狀態膠囊；macOS 14、15 退回一般材質。

Install

三行指令。

或直接從 Releases 下載已簽名、已公證的版本。從原始碼建置約一分鐘，外加一次性的 1.2 GB 模型下載。

git clone https://github.com/mickyyang-1407/utuvo-type.git && cd utuvo-type
./scripts/bootstrap-runtime.sh   # Python venv＋Qwen3-ASR 模型，一次性
./scripts/build-app.sh           # dist/UTUVO Type.app
本機引擎需要 Apple siliconmacOS 14+・26+ 有 Liquid GlassFast 需 8 GB 記憶體・本機 editor 建議 16 GB模型約占 1.5 GBIntel Mac 可走雲端或系統內建語音

DMG 很小：語音模型不在裡面。設定 → 一般 → 安裝本機引擎會把 Qwen3-ASR 0.6B（約 1.2 GB，一次性）下載到你的 Application Support 資料夾。你沒按之前不會下載任何東西。
